# Analysis of Social Media Usage Among Students

Tiny Project for R Markdown.

## Files
- `social_media_usage_tiny_project.Rmd` — R Markdown source file.
- `social_media_usage_students.csv` — fictional dataset of 30 students.
- `social_media_usage_tiny_project_output.html` — ready-to-view project output/preview.
- PNG files — plots used in the project.

## How to knit in RStudio
1. Put the `.Rmd` and `.csv` files in the same folder.
2. Open the `.Rmd` file in RStudio.
3. Click **Knit**.
4. Select HTML output.

The R Markdown uses base R functions, so no additional analysis package is required.
