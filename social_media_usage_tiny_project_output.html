1. Introduction

This Tiny Project analyzes a small fictional dataset of 30 students to study daily social media usage, study time, sleep hours and academic performance.

2. Data Importing

The data are imported from social_media_usage_students.csv using read.csv().

student_data <- read.csv("social_media_usage_students.csv")
head(student_data)
str(student_data)

3. Data Preprocessing and Cleaning

Two missing numeric observations were included intentionally. They were detected with is.na() and replaced using the median.

Missing values after cleaning: 0 in all columns.

9. Findings

  1. Students use social media for communication, education, entertainment and socializing.
  2. Average daily usage is 3.10 hours.
  3. Usage differs among students.
  4. The platform and purpose charts show differences in usage patterns.
  5. The correlation analysis describes the relationship between social media usage and academic performance for this sample.

10. Conclusion

R can be used to import, clean, summarize and visualize student social media data. This project demonstrates a complete small data-analysis workflow using R.
